# Thai Lottery Result API

Static JSON dataset generated by [`script/update.py`](../script/update.py),
which scrapes any new draws and then renders this API from
`script/output/lottery_full.json`. No server, no build step at request time -
just committed files fetched over HTTPS.

Regenerate everything here with a single command:

```
python script/update.py
```

That writes every file in this folder, which mirrors the root of the
**weirdstudio770/thai-lottery** GitHub Pages site. Push its contents there to
publish; the Flutter app fetches straight from
`https://weirdstudio770.github.io/thai-lottery/`.

## Base URL

```
https://weirdstudio770.github.io/thai-lottery
```

## Endpoints

| Path | Contents |
|---|---|
| `/meta.json` | Prize tier config (amounts, match rule) and labels/month names in en/mm/th. Rarely changes. |
| `/settings.json` | `data_version`, latest draw date, total draw count, announcement text. Fetch this first; only re-fetch data if `data_version` increased. |
| `/latest.json` | The single most recent draw, full detail. |
| `/index.json` | Every draw, compact (date + first prize + last 2 digits), newest first. For history/search lists. |
| `/draws/<year>.json` | Every draw for that year, full detail, newest first. |

Example: `https://weirdstudio770.github.io/thai-lottery/draws/2026.json`

## Languages

`en` (English), `mm` (Myanmar), `th` (Thai). Ticket numbers are digit
strings and are language-independent; only `date_label` and `meta.json`
labels are localized, precomputed at build time so the app never needs
locale-aware date formatting for Myanmar/Thai.

## Schema

A full draw record (used in `latest.json` and `draws/<year>.json`):

```json
{
  "date": "2026-08-01",
  "date_label": {
    "en": "1 August 2026",
    "mm": "1 ဩဂုတ် 2026",
    "th": "1 สิงหาคม 2569"
  },
  "source_url": "https://www.lottery.co.th/lotto/1-08-69",
  "results": {
    "first_prize": "932479",
    "near_first_prize": ["932478", "932480"],
    "second_prize": ["397674", "..."],
    "third_prize": ["035383", "..."],
    "fourth_prize": ["061038", "..."],
    "fifth_prize": ["011907", "..."],
    "front_3_digits": ["413", "672"],
    "back_3_digits": ["154", "039"],
    "last_2_digits": "69"
  }
}
```

Draws before 2015-12-30 only have `first_prize`, `last_2_digits`,
`front_3_digits`, `back_3_digits` - the source site has no per-draw detail
page that far back, so `near_first_prize` / `second_prize` / `third_prize` /
`fourth_prize` / `fifth_prize` are `null`.

An `index.json` entry is the compact form:

```json
{
  "date": "2026-08-01",
  "date_label": { "en": "...", "mm": "...", "th": "..." },
  "first_prize": "932479",
  "last_2_digits": "69"
}
```

## Regenerating

After running `scrape_lottery.py` to pull new draws:

```bash
python script/build_api.py
```

Then push this folder's contents to the root of the
weirdstudio770/thai-lottery Pages repo.

To throw away the scraped dataset and the HTML cache and refetch the whole
archive from the source site (several hundred requests):

```bash
python script/update.py --renew
```
