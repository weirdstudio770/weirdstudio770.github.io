Built with Soul, Not Spreadsheets

Weird Studio is my personal independent laboratory. In a mobile landscape inundated with corporate subscription paywalls and copy-paste templates, I build lightweight, responsive utilities that respect user privacy, run offline when possible, and solve real niche needs.

From preserving Myanmar’s astrological calendar dates and Dhamma recordings to building Bluetooth receipt-printing POS tools for small shop owners, every line of code is designed, coded, and cared for by a solo craftsman.
